This project focuses on developing an AI-assisted aptamer screening workflow and a nanozyme-based colorimetric sensing platform for cardiac troponin I (cTnI) detection. The workflow integrates a biophysical-guided gated convolutional attention network (Bio-GCAMNet) for protein–aptamer interaction prediction with sequence mutagenesis, molecular docking, molecular dynamics simulations, and in vitro binding validation. The sensing platform combines Apt-361-mediated molecular recognition, CuS-Pt nanozyme-based catalytic signal amplification, liposomal signal reporting, and magnetic bead-based capture. The project also covers nanomaterial characterization, assay optimization, specificity assessment, and evaluation in serum matrices.
